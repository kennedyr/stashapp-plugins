# stashapp-plugins Repository

This repository hosts custom plugins for StashApp.

## Installation

Add this repository as a plugin source in StashApp:

1. Go to **Settings > Plugins**.
2. Click **Sources** -> **Add Source**.
3. Enter:
   - **Name**: stashapp-plugins
   - **URL**: `https://kennedyr.github.io/stashapp-plugins/main/index.yml`
4. install new plugin from the **Available** tab.

## Plugin Details

Connects StashApp to ossm-sauce to use Funscripts synced with your scenes.

See [plugins/ossm-interactive/README.md](plugins/ossm-interactive/README.md) for usage details.
